# Jira MCP Server Release Notes

This file describes the changes introduced with each version of Jira MCP Server.

## 0.2.0
- Added new `add_issue_components` MCP tool to add components to existing issues
- Enhanced `create_issue` tool with optional `components` parameter for setting components during issue creation
- Added acceptance criteria management tools: `set_issue_acceptance_criteria` and `get_issue_acceptance_criteria`
- Comprehensive component validation and error messaging

## 0.1.1
- Features: Doors requirements traceability, collaboration links, traceability matrices with coverage analysis, bulk operations, and high-performance parallel processing.
- Bug Fixes: Fixed HOST_PORT error message, case-sensitive link type comparison, and improved parallel worker scaling.

## 0.1.0
- Added pagination support to jira_request tool

## 0.0.0
- Initial beta release
