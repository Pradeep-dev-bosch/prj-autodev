# WebEA MCP Server Release Notes

This file describes the changes introduced with each version of the WebEA MCP Server.

## 0.1.0
- Added MCP server transport type as a user input.
- Made password input for authentication a secret input in VS Code.
- Removed the feature allowing target package selection as a user input.
- Restricted destructive SQL operations in MCP tool queries.
- Fixed bug in URL encoding of SQL queries.

## 0.0.0
- Initial beta release.
