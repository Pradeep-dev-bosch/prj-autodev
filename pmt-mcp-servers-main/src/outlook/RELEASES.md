# Outlook MCP Server Release Notes

This file describes the changes introduced with each version of Outlook MCP Server.

## 0.0.0
- Initial beta release with comprehensive Outlook integration
- Email operations: list, search, send, reply, forward, move, delete
- Draft email management: create, update, send drafts
- Calendar operations: list, create, update, delete, cancel events
- Contact management: list, search contacts
- Mail folder operations
- OAuth 2.0 Authorization Code Flow with PKCE
- Bosch CD 07900 compliant (ConfidentialClientApplication)
- Support for shared mailboxes, calendars, and contacts
- Teams meeting integration
